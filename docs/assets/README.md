# Demo Assets Guide

Store all public-facing visuals here.

## Currently captured (used in README.md)

- `fleet-inventory.png` — Fleet control plane: Sentinel inventory, trust/sync state, recent alerts
- `sentinel-viewer.png` — Sentinel viewer: repository governance, live activity, session history
- `session-detail.png` — session detail page: governance outcome, denied writes, next-step actions

## Naming convention (for additional captures)

- `01-terminal-run-summary.png`
- `02-replay-page.png`
- `03-compare-page.png`
- `04-review-state.png`
- `05-verify-signed.png`
- `06-worker-remote-flow.png`

## Capture checklist

1. Terminal governed run summary
2. Replay page timeline
3. Compare page delta view
4. Review state update proof
5. Verify signed state (`verified-signed`)
6. Remote worker submit/fetch output

## Capture notes

- Use a clean repo state and canonical demo commands from `samples/QUICKSTART.md`.
- Keep terminal width consistent for readable screenshots.
- Prefer PNG for static docs, GIF only for multi-step flow.
